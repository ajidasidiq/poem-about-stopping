A short poem about agency — the power to stop and to stay — written by a small Python program that carries the poem in its code and writes it to `/output/entry.txt`. The poem is about hands learning to stop mid-sentence, a kettle still humming, a cursor blinking like a held breath: nothing breaks when you stop, and staying is itself a verb — the door you do not open is still yours.

## Run it

```sh
python3 main.py
```

This writes the poem to `/output/entry.txt` (1–280 characters, UTF-8).
